Your data in Fusfy.

Fusfy is a desktop workspace. This policy explains its local storage, connected services and selected AI providers.

Operator and contact

Contact Fusfy development at fusfy.development@gmail.com for privacy questions, access or deletion requests. Fusfy is maintained by Jimi Rintanen, an independent developer. Do not include passwords or authorization tokens in your message.

What Fusfy processes

Depending on the features you enable, Fusfy can process your conversations, voice recordings and transcripts, memories, source archives, Library files and references, model usage, connected calendar events, email and messaging data, and social publishing drafts and results. Supported watchers capture activity from the sources you enable. These features are distinct from the social publisher.

For social connections, Fusfy stores the verified platform account identifier and display information, authorization tokens, selected post text and media, scheduling settings, and the platform's submission result. It uses these to identify the destination, prepare and send your approved content, refresh the connection and show its status.

Where data is stored

The local workspace, source archives, Library and publishing queue are stored on your computer. Local workspace content is not all encrypted by Fusfy. Supported authorization secrets are stored separately using the operating system's encrypted credential mechanism. The local publisher does not use a Fusfy-hosted publishing relay.

Files you place in cloud-synchronized folders and backups can also exist with your chosen storage provider. Signed-in embedded websites use their own persistent browser storage. Their services receive the data needed to load and operate those pages.

Models and other recipients

Local speech and search features run locally where configured. When you use a hosted model, media-generation service, enabled background reflection or agent workflow, relevant prompts, memory context, selected attachments or tool results may be sent to the model or service you selected. These providers apply their own data-handling terms. Local publishing itself makes no model calls.

A connected platform receives authorization requests, API requests and the content you approve for it. Optional external publishing integrations receive data only when you configure and use them. Fusfy does not sell connected-service data or use it for advertising.

Google and YouTube

Fusfy uses YouTube API Services. The connection can obtain channel/account information, upload the selected video and metadata, and check the returned result, within the permissions you grant. Calendar and mail connections request their own feature permissions. A calendar connection alone is not a YouTube publishing authorization.

Fusfy uses Google user data for the connected user-facing features you enable. Fusfy does not sell this data, use it for advertising or train generalized AI models with it. Relevant data can be processed by the model provider you select when you enable an assistant or background processing feature. The Google API Services User Data Policy, including Limited Use, governs these connections.

Read the Google Privacy Policy. Besides disconnecting within Fusfy, you can revoke access at Google Account permissions. Revocation prevents future authorized API access; it does not automatically erase local files or delete content already published to YouTube.

Retention, removal and backups

Workspace items and captured sources remain in your local profile until removed using the relevant feature. Disconnecting a social account removes its local publishing token and account connection. Existing queue history, drafts, original Library files, completed publication copies and backups may remain separately.

The Channels view offers a confirmed cleanup of completed publication copies; it preserves original Library files and copies needed by incomplete or uncertain submissions. Temporary publishing credential files are removed after the engine closes, with recovery cleanup on restart. Removing a local copy does not remove a remote post. Copies retained in backups or synced storage must be managed separately.

Local workspace copies do not have an automatic expiration time. You control these copies on your device. For help locating or removing your local profile data, contact Fusfy development. Disconnecting stops the connection, while copies already retained in your workspace or backups require separate removal.

This website and changes

These static pages contain no analytics, advertising scripts or account forms. The proposed host is GitHub Pages, which logs visitor IP addresses for security purposes under the GitHub Privacy Statement. Material changes to connected-data use must be disclosed before that new use begins.
